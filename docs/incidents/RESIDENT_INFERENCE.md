# 상주 모델과 요청별 취소

2026-09-08 로컬 구현. Kubernetes 배포 검증은 별도다.

## 모델 수명주기

| 구성 요소 | 포트 | 수명 |
| --- | --- | --- |
| VLM API | 8001 | 요청 간 유지, HTTP 어댑터 |
| llama-server | 8003 | SmolVLM2 Q4_K_M 및 mmproj Q8_0를 한 번 로드하고 유지 |
| Music API | 8002 | MusicGen 모델을 프로세스 시작 시 한 번 로드하고 유지 |

AI 요청에서는 subprocess 생성, SIGKILL, 프로세스 종료를 사용하지 않는다.
음악 모델은 스레드에서 공유하며 작업별 잠금이 모델 동시 접근을 막는다.
VLM은 HTTP 스트리밍으로 호출한다. Docker/Kubernetes에서는 같은 Pod의 상주 llama-server에 연결할 수 있다.
`start-llama.sh`는 서비스 시작용이며 API 요청에서 호출하지 않는다.

## MusicGen 취소

Transformers 4.57.5의 MusicGen generate는 stopping criteria가 True여도 뒤이어 오디오를 디코딩한다.
따라서 작업의 Event가 설정되면 사용자 정의 StoppingCriteria에서 JobCancelled 예외를 발생시켜 부분 오디오 디코딩으로 넘어가지 않는다.
EnCodec 하위 모듈의 forward 전 확인도 추가하고 finally에서 훅을 제거한다.
디코딩 내부 native 연산 하나를 선점하는 것은 아니며 다음 훅/완료 지점까지 기다린다.
모델 자체는 교체하지 않는다. 취소 완료는 스레드가 실제로 종료된 뒤 반환한다.

## VLM 취소

검증 엔진: llama.cpp 0.3.0, build 10621, commit c1d0e7a00.
단일 전용 서버에 `--parallel 1 --slots`를 설정한다.
수락 응답 헤더 이후에 스트림을 닫아 늦은 요청 시작과 취소의 경합을 줄이고,
`/slots`의 `is_processing=false`를 확인한 뒤 작업 잠금을 해제한다.
스트림 종료가 곧 추론 완료라고 가정하지 않는다. 실제 서버 로그의 cancel task 및 slot release도 검증했다.

서버 수락 전 취소라면 수락 응답 또는 HTTP 실패까지 기다릴 수 있다.
이미지 인코딩/프리필/native 연산은 엔진이 취소를 처리할 수 있는 지점까지 진행할 수 있다.
서버 상태를 확인할 수 없으면 취소 완료라고 응답하지 않고 슬롯 상태를 재확인하며 잠금을 유지한다.
이때 UI는 202 응답을 받아 계속 중단 상태를 확인한다. 서버 복구가 필요할 수 있다.
서버를 다른 클라이언트와 공유하거나 API를 여러 프로세스로 늘리는 것은 이 구현의 범위 밖이다.

## 검증

- 자동 테스트: 실행 중 취소가 스레드 정리까지 기다림, 모델 재사용, 대기 작업 취소, 시작 전 취소, HTTP 호출자 종료 시 잠금 유지.
- 실제 API: 음악 연속 생성 2회 및 취소 후 재생성 성공. 관측 시간 8.91초/5.52초, 취소 확인 약 0.13초.
- 실제 API: VLM 연속 분석 2회 및 취소 후 재분석 성공. 관측 시간 8.92초/1.95초, 취소 확인 약 0.23초.
- 동일 이미지 재분석에서는 llama-server 프롬프트 캐시도 재사용된다. 위 차이를 모델 로딩 시간으로 해석하지 않는다.
- llama-server 모델 로딩 로그 1회, MusicGen 모델 로딩 로그 1회. 취소 후에도 같은 서버 PID 유지.
- 캐시되지 않은 다른 이미지의 초기 분석 중 취소도 검증했다. 약 5.28초 후 슬롯 유휴 확인, 모델/API PID 유지. 초기 native 연산은 즉시 선점되지 않는다.
- 시간은 해당 테스트 관측치이며 보장 성능이 아니다. 모든 이미지 크기·디코딩 타이밍·GPU·다중 Pod 조합을 검증한 것은 아니다.

## 실행

[SETUP.md](../SETUP.md)를 따른다. 상주 llama-server를 먼저 시작하고 두 API 및 Next.js를 실행한다.
기존 프로세스 강제 종료 방식으로 돌아가지 않도록, 연속 요청에서 모델 재로딩이 없는 것을 회귀 검증한다.
